# Race to 270 — public support pages

Static support and privacy pages for the Race to 270 iPhone game.

- Support: https://khakhibuzz.github.io/raceto270-support/support/
- Privacy: https://khakhibuzz.github.io/raceto270-support/privacy/
- Contact: khakhibuzz@gmail.com

Hosted by GitHub Pages from the main branch root. This repository contains only public website content. No app source, credentials or user campaign data is included.

In the app workspace, edit `docs/release/SUPPORT.md` or `PRIVACY_POLICY.md`, then run `python3 scripts/build_support_site.py`. Commit the resulting files in `support-site/` and push to publish updates. The CSS is maintained directly in this repository.
